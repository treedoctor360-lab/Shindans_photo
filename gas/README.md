# サーバー（Google Apps Script）の置き方

アプリの入力データを受け取り、Google スプレッドシートに保存するサーバーです。
設定ファイル・野帳の原本・台帳も、ここを通してスマホに配ります。

## 1回だけ行う準備

1. **スプレッドシートを作る**
   Google ドライブで、新しいスプレッドシートを作ります（名前は自由。例：「点検データ 2099」）。
   1業務（年度×地区）につき1つ作ります。
2. **スクリプトを貼る**
   スプレッドシートのメニュー「拡張機能」→「Apps Script」を開きます。
   最初からある `コード.gs` の中身を全部消して、このフォルダの `Code.js` の中身を全部貼り付け、保存（💾）します。
3. **合言葉を決める**
   Apps Script の左の「⚙ プロジェクトの設定」→ 一番下の「スクリプト プロパティ」→「スクリプト プロパティを追加」。
   - プロパティ：`PASSPHRASE`
   - 値：合言葉（他人に推測されにくい、長めの文字。例：単語を3つ以上つないだもの）

   ※ スクリプトは必ず手順2のとおり、**スプレッドシートの「拡張機能」→「Apps Script」から**作ってください。
   ドライブの「新規」→「Apps Script」で独立したファイルとして作った場合だけ、もう1つ追加が必要です。
   - プロパティ：`SPREADSHEET_ID`
   - 値：スプレッドシートの URL の `/d/` と `/edit` の間の文字
4. **公開する**
   右上の「デプロイ」→「新しいデプロイ」→ 種類の選択（⚙）で「ウェブアプリ」。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   「デプロイ」を押し、Google アカウントへのアクセスを「許可」します（「このアプリは確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」）。
   表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）を控えます。
5. **アプリに入れる**
   アプリの「設定」→「サーバー」に URL と合言葉を入れ、「接続を確認する」を押します。

## 使い方

- 事務所の PC：設定ファイル・野帳の原本・台帳を読み込み →「この端末の設定・原本・台帳をサーバーに置く」
- スマホ：「サーバーから設定・原本・台帳を受け取る」→ 入力。保存のたびに自動で送信します
- 事務所の PC：「出力」→「サーバーから最新を受け取る」→ 一覧表・野帳を出力
- 前回の調査：事務所の PC の「設定」→「前回の調査（カルテ）」でカルテのファイルをまとめて選び、「サーバーに置く」。スマホは「サーバーから受け取る」で要点を受け取り、写真は入力画面か「前回の写真をすべて端末に入れる」で端末に入れます。
- 送信と受信は、起動時・保存のたび・電波が戻ったときにも自動で行います。
- 「設定」→「サーバー」で、この端末を使う人（調査者／事務）と名前を選びます。付箋・確定に「誰が」として残ります。

## 注意

- 「アクセスできるユーザー：全員」は、URL を知っていて**合言葉も合う人だけ**が使えるという意味です。URL と合言葉はアプリの中にだけ入れ、メールやチャットに貼らないでください。
- `Code.js` を直したときは、貼り付けて保存したあと「デプロイ」→「デプロイを管理」→ 鉛筆マーク →「バージョン：新しいバージョン」→「デプロイ」。**保存しただけでは切り替わりません。** この方法なら URL は変わりません（「新しいデプロイ」を作ると URL が変わります）。
- 次の年度・別の地区で使うときは、新しいスプレッドシートを作って手順1〜5をやり直します。
- 受信したデータはシート「records」に1件1行で入ります（木の入力内容・付箋・確定の印。それぞれ版番号つき）。最初にデータが届いたときに作られます。**このシートは手で直さないでください**（版番号が合わなくなります）。
- シート「history」には、保存のたびに1行ずつ履歴が残ります（いつ・誰が・何を）。
- 前の形のシート「trees」が残っている場合、今のサーバーはもう使いません。アプリを新しくすると、入力済みの木は「records」へ自動で送り直されます。確認できたら「trees」は消してかまいません。
- 置いたファイルは、スプレッドシートと同じフォルダの「データ」フォルダに入ります（前回の調査は、要点 `prevIndex.json` と場所ごとの写真 `prevPhotos:p1.json` …）。置き直すと前のファイルはゴミ箱に移ります（30日間は戻せます）。
- 写真（試作）：シート「photos」に1枚1行（写真の印・ファイルの印・撮り直しの印など）、本体は「データ」フォルダの中の「写真/公園・路線」フォルダに入ります。撮り直す前の写真も消さずに残します。**このシートも手で直さないでください。**
- 写真の試作は、本番とは別のスプレッドシート・GAS で動かしてください（本番の記録に写真の行を混ぜないため）。
