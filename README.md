# Shindans_photo

樹木点検の野帳入力アプリに、写真（カメラ）の機能を足した**試作版**です。元は [shindans](https://github.com/treedoctor360/shindans) の写しです。

- アプリ：https://treedoctor360-lab.github.io/Shindans_photo/ （スマホでは「ホーム画面に追加」すると、電波がなくても開けます）
- 本番の野帳アプリとは、端末内の保存場所・サーバー（GAS）を分けて使います（入力内容が混ざらないように）。
- 使うには、設定ファイル・野帳の原本・台帳とサーバー（`gas/`）が必要です。これらはリポジトリには含めていません。

## 写真（この試作で足したもの）

- 入力画面の「写真」に、その木で撮る写真の枠（全景・弱点など。今までの「撮る写真」の判定と同じ）が並びます。「撮る」を押すとスマホのカメラが開きます。
- 撮った写真は、決まりの大きさ（4:3、640×480、1枚 100KB 程度）に整え、名前（樹木番号＋写真の名前＋診断日）を付けて、まず端末に保存します。向きが決まりと違えば知らせます。
- 撮り直すと新しい写真を使います。前の写真は消さずに「撮り直し」の印を付けて残します（サーバーにも残ります）。
- 電波があれば、入力内容を送った後に写真もサーバー（Google ドライブの「データ/写真/公園・路線」）へ送ります。届いた大きさを確かめます。
- 事務所の PC では写真を見られ（撮れません）、「出力」→「写真を ZIP で出す」で公園・路線ごとのフォルダに分けて出せます（ZIP を読み直して検査してから保存）。
- 一覧のカードに「写真 撮った枚数/撮る枚数」が出ます。

### 端末のデータを消さないために

- 写真は入力内容と別の場所（端末内のデータベース）に置きます。写真の保存に失敗しても、入力内容には響きません。
- 写真と一緒に写真の記録の写しも置き、記録が保存できなかったときは次に開いたときに戻します。
- 送信済みの写真も、端末に本体を残します。外すのは、端末の空きが少ないときか、端末に残している写真が 300MB を超えたときだけで、送信済みの古い写真からです（小さな見本は残ります）。未送信の写真は外しません。
- 端末の空きが少ないときは、写真を保存しません（入力内容が保存できなくなるのを防ぐため）。
- 起動時に、ブラウザへ「この端末のデータを勝手に消さない」よう申し出ます。

## 確認の流れ

1. 調査者（スマホ）が入力・保存すると、自動でサーバーへ送ります（提出）。
2. 事務（PC）が受け取り、気になる項目に付箋を付けます（質問と修正案）。事務の端末では入力内容は直しません。
3. 調査者に付箋が届きます。「修正案を採用／このままで良い／自分で直す／返事を書く」で答えます。採用すると修正案がそのまま入力内容に入ります。
4. 事務が返事を読んで「確認済み」にし、木を確定します。付箋のない木はまとめて確定できます。確定の後で入力内容が変わると、確定は外れます。
5. 一覧表には確定した木だけを書き込みます（途中経過を見るときは「未確定の木も書き込む」）。野帳は確定に関係なく入力どおりに出します。

## 前回の調査

事務所の PC で前回のカルテ（1本1シートの Excel。種類は複数可）をまとめて読み込み、サーバーに置きます。スマホは受け取るだけで、入力画面に前回の弱点・評価・写真・図が種類ごとに出ます（写真は場所ごとに端末へ入れておけば、電波がなくても見られます）。

「設定」→「サーバー」で、端末ごとに調査者／事務と名前を選びます。同じ木を2台で直したときは上書きせず、どちらの内容を使うかを選びます。
