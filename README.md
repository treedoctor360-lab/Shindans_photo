# Shindans_photo

樹木点検の野帳入力アプリに、写真（カメラ）の機能を足した**試作版**です。元は [shindans](https://github.com/treedoctor360/shindans) の写しです。

- アプリ：https://treedoctor360.github.io/Shindans_photo/ （スマホでは「ホーム画面に追加」すると、電波がなくても開けます）
- 本番の野帳アプリとは、端末内の保存場所・サーバー（GAS）を分けて使います（入力内容が混ざらないように）。
- 使うには、設定ファイル・野帳の原本・台帳とサーバー（`gas/`）が必要です。これらはリポジトリには含めていません。

## 確認の流れ

1. 調査者（スマホ）が入力・保存すると、自動でサーバーへ送ります（提出）。
2. 事務（PC）が受け取り、気になる項目に付箋を付けます（質問と修正案）。事務の端末では入力内容は直しません。
3. 調査者に付箋が届きます。「修正案を採用／このままで良い／自分で直す／返事を書く」で答えます。採用すると修正案がそのまま入力内容に入ります。
4. 事務が返事を読んで「確認済み」にし、木を確定します。付箋のない木はまとめて確定できます。確定の後で入力内容が変わると、確定は外れます。
5. 一覧表には確定した木だけを書き込みます（途中経過を見るときは「未確定の木も書き込む」）。野帳は確定に関係なく入力どおりに出します。

## 前回の調査

事務所の PC で前回のカルテ（1本1シートの Excel。種類は複数可）をまとめて読み込み、サーバーに置きます。スマホは受け取るだけで、入力画面に前回の弱点・評価・写真・図が種類ごとに出ます（写真は場所ごとに端末へ入れておけば、電波がなくても見られます）。

「設定」→「サーバー」で、端末ごとに調査者／事務と名前を選びます。同じ木を2台で直したときは上書きせず、どちらの内容を使うかを選びます。
